# Nova NFT - 设计稿

一个现代化的NFT交易平台设计稿，参考主流NFT平台设计，采用独特的视觉风格和交互体验。

## 🎨 设计风格

- **深色主题**: 采用深色背景配合渐变色点缀
- **渐变色彩**: 紫-粉色渐变为主色调
- **毛玻璃效果**: 导航栏使用毛玻璃效果
- **网格背景**: 添加微妙的网格纹理
- **卡片悬浮**: 交互反馈强烈的悬浮效果

## 📁 页面结构

| 页面 | 文件 | 说明 |
|------|------|------|
| 首页 | index.html | Hero区、热门NFT、热门创作者 |
| 市场 | market.html | 筛选、NFT列表、分页 |
| 质押 | stake.html | 质押池、收益概览 |
| 个人中心 | profile.html | 用户信息、钱包、NFT藏品 |

## ✨ 特色功能

### 首页
- 动态渐变背景
- 网格纹理效果
- 数据统计展示
- 分类导航
- 热门NFT卡片
- 创作者排行榜

### 市场
- 多维度筛选（类型、价格、排序）
- NFT卡片展示
- 拍卖倒计时
- 分页导航
- 收藏/分享功能

### 质押
- 质押池展示
- 年化收益率
- 质押进度
- 我的质押记录
- 收益统计

### 个人中心
- 用户资料卡
- 钱包概览
- NFT藏品管理
- 交易记录
- 标签页切换

## 🚀 技术特点

- 纯HTML/CSS/JavaScript实现
- 响应式设计
- CSS Grid布局
- CSS渐变和阴影
- 原生JavaScript交互
- 无外部依赖

## 📱 响应式断点

- PC: > 1200px
- 平板: 768px - 1200px
- 手机: < 768px

## 🎯 设计参考
